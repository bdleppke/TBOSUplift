# Modifying the uplift Program

The main program is located inside main.cpp.



# Build Process

 1. Make a build directory `mkdir build`
 2. CD into it `cd build`
 3. Generate cmake `cmake ..`
 4. Make the code `make`
 5. Execute the code `./uplift`
